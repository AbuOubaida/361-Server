বন্ধ
ডিফল্ট পোর্ট ৮০। ৮০ ব্যস্ত থাকলে ৮০৮০ দিন। পোর্ট বা সার্ভার বদলাতে আগে সার্ভার বন্ধ করুন।
Apache-তেও এখন PHP, www ফোল্ডার, ভার্চুয়াল হোস্ট (.test), .htaccess আর Adminer/phpMyAdmin কাজ করে। সার্ভার বদলালে আগে চলমানটা বন্ধ করুন।
ডাটাবেস
www ফোল্ডারে নতুন সাবফোল্ডার (যেমন blog) বানিয়ে রিফ্রেশ চাপলে blog.test নামে সাইট পাবেন। ফোল্ডারের ভেতরে public থাকলে (Laravel) সেটাই root হবে।
নাম দিন (যেমন blog), তারপর বাটন চাপুন। WordPress-এর জন্য MySQL চালু থাকতে হবে। ডাটাবেস নিজে বানাবে।
চালুঠিকানাফোল্ডারPHPসেশন (মিনিট)নেটওয়ার্ক (LAN)কনফিগ
Node.js অ্যাপ
www-র যে সাবফোল্ডারে package.json আছে সেটা Node অ্যাপ।
PHP, Nginx, Apache, MySQL, PostgreSQL বা phpMyAdmin-এর নতুন ভার্সন চাইলে এখান থেকে যোগ করুন। ZIP-এর লিংক দিন, অথবা নিজের পিসিতে নামানো ZIP বেছে নিন। যোগ করার পর "ব্যবহার করুন" চাপলেই ওই ভার্সনে চলবে। পুরনো ভার্সনও থাকবে, যেকোনো সময় ফেরা যাবে। ভার্সন বদলাতে সংশ্লিষ্ট সার্ভার বন্ধ থাকতে হবে।
PHP Extension
একটা PHP ভার্সন বেছে তার extension চালু/বন্ধ করুন। এটা ওই ভার্সনের সব সাইটে একই থাকে। বদলের পর ওয়েব সার্ভার বন্ধ করে আবার চালু করতে হবে। mbstring, openssl, curl, mysqli, pdo_mysql, fileinfo বন্ধ করলে WordPress/Laravel চলবে না।

ডাটাবেস
MySQL root পাসওয়ার্ড
MySQL চালু থাকতে হবে। বসালে নতুন WordPress/Laravel সাইট, phpMyAdmin ও MySQL বন্ধ করা এই পাসওয়ার্ডে চলবে, আর পুরনো WordPress (wp-config.php) ও Laravel (.env) সাইটেরও পাসওয়ার্ড নিজে বদলে দেওয়া হবে। অন্য Node/হাতে বানানো প্রজেক্ট আপনাকে নিজে ঠিক করতে হবে। Adminer-এ লগইনে এই পাসওয়ার্ড দিন। পাসওয়ার্ড সেটিংস ফাইলে (settings.json) সাধারণ লেখায় থাকে। প্রতি MySQL ভার্সনের পাসওয়ার্ড আলাদা।
